Nostos is a live-programming language: saving a file never touches the running system. To deploy your change, commit the file to the live system with Ctrl+Alt+C (or Tools | Nostos | Commit File to Live System).

Files whose editor content the live system has not seen yet are marked with a blue dot on their file icon, in the editor tabs and in the project tree. A yellow dot means something the file depends on changed underneath it.
