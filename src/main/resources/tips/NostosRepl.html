The Nostos REPL tool window at the bottom of the IDE evaluates expressions in the same running live system your editor talks to, so functions you have committed with Ctrl+Alt+C are callable right away.

Use Ctrl+Space to complete at the prompt, Up/Down to walk the input history (kept across restarts), Ctrl+C to abandon the current line, and Ctrl+D to end the session. The + button on the tab strip opens more REPL tabs; they all share the same live system.
